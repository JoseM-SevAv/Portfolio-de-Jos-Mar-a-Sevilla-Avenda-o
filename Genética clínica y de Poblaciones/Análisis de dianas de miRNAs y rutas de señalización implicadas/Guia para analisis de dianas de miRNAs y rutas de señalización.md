Para ver las posibles dianas de miRNAs en los diferentes genes podemos usar páginas como <a href="https://www.targetscan.org/vert_80/"> TargetScan</a><br/> o <a href="https://mirdb.org/"> miRDB</a><br/>, lo que nos dará una lista de todos los genes a los que nuestro miRNA puede unirse.

Una vez tengamos una lista de genes para cada uno de los miRNAs, podemos ver los genes a los cuales se unan la mayor cantidad de miRNA posible, obteniendo de esta forma el gen diana, se puede ver apuntando la lista de genes diana de cada uno de los miRNAs, comparando las diferentes listas obtenidas de los miRNAs. Esto se puede hacer mediante un diagrama de Venn, podemos usar la página de <a href="https://www.interactivenn.net/"> InteractiVenn</a><br/>.
